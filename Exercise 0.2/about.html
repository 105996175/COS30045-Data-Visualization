About Us

The Appliance Energy Consumption website was created to help users understand how household appliances use electricity.

The website provides simple information about appliance energy consumption and demonstrates how web technologies such as HTML, CSS and JavaScript can be used to create an interactive website.

Purpose of This Website

The purpose of this website is to provide easy-to-understand information about household appliance electricity usage and encourage awareness of energy consumption.

Website Features

  • Information about appliance energy consumption
  • Television energy usage examples
  • An interactive FAQ section
  • Consistent navigation across all pages
