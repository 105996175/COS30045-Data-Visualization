# COS30045 Exercise 3 – Communicating Data Insights

## Data Story

### Audience

The target audience is consumers who are planning to purchase a
television and want to compare screen size and energy efficiency.
The visualisations use straightforward charts and explanations so
that readers do not need technical data-analysis knowledge.

### Questions

This data story answers the following questions:

1. How frequent is each size of TV?
2. How does screen size impact energy consumption?

## About the Data

### Data Source

The television energy-consumption dataset was provided as part of
the COS30045 course materials. It contains television product
information, including screen size, screen technology and labelled
yearly energy consumption.

### Data Processing

The data was processed using KNIME. The workflow included reading
the CSV file, filtering relevant columns, cleaning and replacing
inconsistent values, filtering rows and preparing the required
attributes. A histogram was used to examine screen-size frequency,
while a scatter plot was used to compare screen size with labelled
yearly energy consumption.

### Privacy

The dataset contains television product information and does not
contain personally identifiable or sensitive information.

### Accuracy and Limitations

The dataset may not represent every television currently available.
Product information may change over time, and labelled yearly energy
consumption may differ from actual household usage.

### Ethics

The charts are presented with explanatory text and without altering
the visible results. Conclusions are limited to patterns shown in the
provided dataset and should not be interpreted as representing every
television model.

## AI Declaration

Generative AI (ChatGPT by OpenAI) was used to assist with understanding
the exercise requirements, planning the six-stage storyboard, structuring
the data-story webpage, generating example HTML and CSS, and reviewing
the written explanations. The KNIME data processing and visualisation
