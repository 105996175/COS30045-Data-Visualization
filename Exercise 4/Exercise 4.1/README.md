# Exercise 4.1: Draw SVGs

## Overview

This exercise demonstrates the use of Scalable Vector Graphics (SVG) to create and customise a house and garden.

The SVG drawing includes different SVG elements such as rectangles, circles, ellipses, lines, paths and text. It also demonstrates styling, coordinates, grouping and transformations.

## SVG Features Used

- `<rect>` for the house, door, windows and tree trunk
- `<circle>` for the sun and door handle
- `<ellipse>` for the tree leaves
- `<line>` for the fence
- `<path>` for the roof and garden path
- `<text>` for the SVG title
- `<g>` to group the two windows
- `transform="translate(...)"` to position the window group
- Fill, stroke and stroke-width attributes for styling

## Customisation

The original SVG was customised by changing the position and styling of several elements, including:

- Sun position and colour
- House body position and colour
- Window group position
- Tree ellipse position
- Garden path position and stroke
- Fence size and stroke width

Before and after screenshots are included on the Exercise 4.1 webpage together with a table comparing the SVG coordinates and styling changes.
